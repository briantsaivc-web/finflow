# FinFlow 財商沙盒

台灣在地化的財商桌遊（數位版）。單一 HTML 檔、零相依套件、可離線遊玩，專為 iPad Safari 與 PC 瀏覽器設計，全程繁體中文。

**目前版本：v2.1.2（V11.2 單機版）**　·　線上試玩：https://finflow-brian.netlify.app

## 怎麼玩

用瀏覽器打開 `index.html` 就是完整遊戲——不用安裝、不用網路、不用伺服器。

擲骰前進、抓住機會、管理現金流，從「老鼠圈」畢業走上「自由圈」去完成夢想。內建：股市（現股／融資分倉）、房地產與事業、貸款與浮動利率、通膨、拍賣、合資、P2P 借貸、機會轉介、人生商城與保險、品格帳本、幸福感勝利條件、破產與紓困、電腦對手（多種性格）。

詳細規則見 `manual/`：
- 《快速上手指南》（2 頁，給第一次玩的人）
- 《完整規則手冊》（給想搞懂所有機制的人）

## 部署

任選一種，都是把單一檔案放上去而已：

- **Netlify**：把 `index.html` 拖進 Netlify 部署頁即完成（現行做法）
- **GitHub Pages**：這個 repo 推上 GitHub 後，到 Settings → Pages → 選 main 分支根目錄，`index.html` 會自動成為首頁
- **隨身碟／AirDrop**：直接把 `index.html` 傳到目標裝置，用瀏覽器開啟

## 專案結構

```
index.html      遊戲本體（引擎＋內容＋介面全部內含，交付即此一檔）

docs/           歷次變更說明（一期 → V11.2，共 12 份開發沿革）
tests/          自動化測試（見下方）
```

## 測試

引擎自測（Node.js，30 項，涵蓋帳務平衡、重放決定論、各模組規則）：

```bash
cd tests
python3 extract.py     # 從 ../index.html 抽出引擎程式碼
node runtest.js        # 必須 30/30 通過
```

平衡模擬（200 局統計畢業輪數與跌落率）：

```bash
cd tests && node simtest.js 2.0
```

介面煙霧測試（需先 `npm install playwright` 並安裝瀏覽器；在 repo 根目錄執行）：

```bash
node tests/smoke14.js   # 12 種解析度開局測試；smoke7~13 為各期功能驗證
```

## 設計鐵律（改程式前必讀）

1. **Reducer 純函數**：遊戲狀態只由動作推進，隨機數一律走 `util.rand(S)`（種子化）——同一顆種子＋同一串動作，重放必得同一局。
2. **資料驅動**：所有數值參數都在 `config-default` JSON 區塊，不寫死在程式裡。
3. **帳本即真相**：現金、資產、負債的每一筆變動都過分類帳，帳目永遠要平。
