## 1. 先講三項查證結果——有兩項不是 bug

### 1.1 `<br>` 怪異符號：那是舊版截圖

`el()` 的排版標籤修正在 **v2.4.3-S3b** 就做了。實測四個版本：

| 版本 | `<br>` 是否正確排版 |
|---|---|
| v2.4.2-M8S3 | ✗（`isSafeMarkup` 尚未存在） |
| v2.4.3-S3b | ✓ |
| v2.5.0-S4 | ✓ |
| v2.6.0-S5 | ✓ |

你那張借款面板的截圖是 **v2.4.2 或更早**的。同一批截圖裡有住宅火險（v2.5.0 才有），所以是混了不同時間的畫面。**現行版本沒有這個問題**——如果你在新版還看得到，跟我說，那就是另一條路徑。

### 1.2 天災：其實一直在發生，是呈現讓你沒注意到

60 局實測，三張天災卡出現 **80 次（每局 1.3 次）**：

| 卡 | 60 局出現次數 |
|---|---|
| MA09 強震來襲，老屋受損 | 23 |
| MA10 強颱過境，全台停班停市 | 28 |
| MA11 豪雨土石流，山區聯外中斷 | 29 |

問題在於它跟「央行信用管制」「股市降稅」共用同一句「政策事件：」的公告，一閃就過去了。**已改成分開呈現**：天災用 `🌪 天災：` 開頭、紅色 toast、停留 5 秒。

### 1.3 產險顯示「免費」：這個是真 bug

`E.mallCost` 只算 `payload.cost`，而產險用的是 `annualPremium` → 顯示「免費」，**而且 `mallAffordable` 也跟著繞過檢查**（現金只剩 1 塊也買得下去）。已修：`mallCost` 納入年繳保費，同時移除 `mallApply` 裡的重複加計（否則會扣兩次）。T-56 有「只能扣一次」的斷言。

## 2. 想學財務技能卻找不到

不是 bug，是**設計上的稀缺沒有被說清楚**。`skillPerGame = 6`，技能庫有 14 張，所以每局只有 6 門課會開。實測「記帳與看財報」的進場率只有 **32%**——三局有兩局學不到。

**修法不是提高抽樣數**（那會讓「準備是有限的」這個主張消失），而是**把沒開的課也列出來**：進修選單下方以灰色虛線列出本局沒開的 8 門課，標「（本局沒開）」，並附一句：

> 每局的技能牌是抽樣的，想學的不一定開得成，這本身就是現實的一部分。

滑鼠停留還看得到那門課的 hint 與學費——讓你知道它存在、這局沒有，而不是懷疑程式壞了。

## 3. 品格考驗：把「有品格會怎樣」講出來

你抓到的對比很準——**保險有理賠明細，品格卻只說「這次的代價是 120,000」**，等於沒教到東西。

失敗分支現在多一張對照表：

| | |
|---|---|
| 你現在的「謹慎」 | 0 級（這張卡要 2 級） |
| 實際付出 | −120,000 |
| 若「謹慎」有 2 級 | 完全避開 |
| 這次的差距 | 省下 120,000 |

底下一句：**「品格不是道德分數，是遇到事情時的緩衝——跟保險一樣，平常看不出差別，出事那天才知道。」**

（成功分支原本就有「讓你少付了 X」，維持不動。）

## 4. 每輪紀錄

玩家卡右上角多一個 📜，點下去看**那位玩家**的每輪紀錄（點卡片本身仍是切換檢視，兩個行為不互相干擾）。

每一輪一個區塊，顯示：
- **標題列**：第 N 輪、該輪現金淨變動、當輪的被動收入／支出水位
- **明細表**：發生了什麼｜來源｜現金

「來源」這一欄是新加的。原本事件分錄的摘要寫的是效果標籤（「修繕與停業損失」），看不出來是哪張卡造成的。現在分錄多存一個 `srcTitle`，所以你會看到：

| 發生了什麼 | 來源 | 現金 |
|---|---|---|
| 修繕與停業損失 | 強震來襲，老屋受損 | −35,000 |

資料**全部來自既有的 `p.ledger` 與 `p.history`**，沒有新增任何遊戲狀態，也不影響重放。
