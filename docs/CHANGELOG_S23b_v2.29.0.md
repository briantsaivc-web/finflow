## 1. S23a.1：被動收入分類（E1）

`E.passiveBreakdown(S,p)` 走 `p.assets` 的 kind 分類，三個地方都用它：

| 位置 | 呈現 |
|---|---|
| **每輪紀錄**的「現金流結算」那一列 | 備註攤開：「被動收入 1,479,030＝🏠 租金 620,000　🏪 事業分紅 310,000　📈 股息 549,030」 |
| **薪資單**（發薪動畫） | 被動收入下面縮排列出每一類 |
| **右欄「被動收入」** | 滑過去看得到組成；點下去開**被動收入明細面板**（每一類的佔比長條、底下列出每一筆資產的名稱與金額、算出離財務自由還差多少） |

設計上的一個堅持：**每一列加起來一定等於帳本的 `derived.passiveIncome`**。資產分類算出來的總和若與帳本有差（例如某個事件直接加減 `INCOME_PASSIVE` 而沒掛在資產上），差額會掛成「其他調整」那一列，不讓數字憑空消失。`s23test` 有一項專門驗這件事。

## 2. S23a.1：股息再投入摘要加累積張數（E2）

「股息再投入：本期股息 760,400 → 買 富穩電信 164 張**（累積 1,788 張）**」。`detail.held` 也帶著，定期定額那一列同樣有。計算只算現股（融資倉與已下市的壁紙不混進去）。

## 3. S23a.1：殖利率上限放寬到 21.6%（E3）

`stockYieldCapMonthly` 0.015 → **0.018**。同時把高股息股的地板從 0.25 調到 **0.22**——這兩個數字是配著設計的：地板價 6.16 時 `現價 × 1.8% = 0.1109` 剛好小於面額基準 0.112，上限咬住，年化**正好 21.6%**。地板若留在 0.25，上限永遠咬不到，最高只有 19.2%。

| 股價（面額 28） | 每張股息 | 年化 |
|---|---|---|
| 28（面額） | 0.112 | 4.8% |
| 14 | 0.112 | 9.6% |
| 6.22（上限開始咬） | 0.112 | 21.6% |
| 6.16（地板） | 0.1109 | **21.6%** |
| 2.8（S22 舊地板） | 0.112 | 48.0%（舊制） |

## 4. S23b：M9 進階金融

### 4.1 模組骨架（E7）
- `M.registry.M9`，掛在 `ns.modules.order` 的**最後**——期貨的逐輪結算必須用 M1 更新完的股價。
- `ns.PRESETS`：進階／硬核／沙盒含 M9；**新手與標準不含**，教學局也不開。
- 總開關 `advancedMarketsEnabled`。整包關掉時，模擬器與 1000 局閘門完全不受影響（gate 用的模組清單本來就沒有 M9）。
- NPC 不主動開任何 M9 部位（`npcUsesM9: 0`）；防禦性地讓 `npc.decide` 收到追繳時一律當場平倉。

### 4.2 解鎖
兩條路擇一（Brian 定案：**累計**不是連續）：
- 任一檔股票 `stockHoldTurns` 累計滿 **12 輪**（`E.tickHoldTurns` 每輪結束時累加；賣掉不歸零，買回來接著算）；
- 或學會新技能 **〈衍生性商品與槓桿〉**（`SKL_DERIV`，HIGH／FINANCE，先修財務記帳，學費 45、4 輪、不過時，`moduleReq: M9`）。

未解鎖時：股市面板的期貨區**反灰**並寫明「還差 N 輪持股經驗（已累計 M 輪），或學會〈衍生性商品與槓桿〉」；引擎層所有 `FUT_*` 動作回 `ADV_LOCKED`（介面反灰只是提示，把關在引擎）。

### 4.3 期貨（可作多放空）
| 項目 | 規則 |
|---|---|
| 標的 | 大盤 ETF；一口合約值 ＝ ETF 現價 × **10** |
| 保證金 | 開倉付合約值 **10%**，記成 `kind:"FUTURES"` 的資產（`marketValue` ＝保證金餘額，`monthlyIncome` 0——不算被動收入） |
| 方向 | `long` / `short`；同標的不能多空同時持有（`OPPOSITE_POSITION`），同方向加碼併倉 |
| 逐輪結算 | `E.tickFutures`：損益 ＝(新價 − 前價) × 10 × 口數 × 方向，直接加減保證金餘額並記一筆 `ASSET` 分錄 |
| 追繳 | 餘額 < 合約值 × **5%**（學過衍生性商品 4%）→ 記在 `p.pendingFutCall`，**等他自己的回合**才跳決策卡（S15d 的死結教訓）。三選一：補到原始保證金／當場平倉／賭下一輪 |
| 強制平倉 | 餘額 ≤ 0 直接強平；**穿價的部分轉成信用貸款**留在身上（與融資斷頭同一條路），並推一張 ACK 揭曉卡 |
| 口數上限 | 信用 A 5／B 3／C 1（`E.futMaxLots`） |
| 手續費 | **每口定額**（E4，`futFeePerLot` 0.3），開倉與平倉各收一次 |

實測數字：ETF 現價 56.45 → 一口合約值 564.5、保證金 56.45。ETF 漲 5%，一口多單賺走保證金的 **50%**——十倍槓桿的意思就是這個。ETF 跌 20% 時保證金穿價，欠款轉信貸。

### 4.4 介面
- 股市面板最上方新增「⚡ 期貨（進階金融）」區塊（刻意放最上面：它是這一頁最危險的東西，不該藏在最下面）。列出標的現價、一口合約值、一口保證金、手續費、口數上限與已開口數；口數拉桿＋「📈 作多」「📉 放空」；下面列出現有部位（保證金、維持線、維持率，追繳中會標紅）與平倉鈕。
- 追繳決策卡：三個選項各自寫清楚後果，附「槓桿的真正風險不是賠錢，是還沒等到你看對，錢就先燒完了」。
- 拒絕碼中文：`ADV_LOCKED`、`NO_M9`、`FUT_LOT_LIMIT`、`OPPOSITE_POSITION`、`NO_POSITION`。

### 4.5 E5：成長股下市後
`E.cardUsable` 原本就有「已下市的股票不會再有人賣給你」（對任何 symbol 通用），成長股與投機股行為本來就一致，不需另外改。已在 S23b 回查確認。
