# FinFlow 變更說明 — 多人連線實測 V2 修訂 v2.2.2

日期：2026-08-27　·　基底：v2.2.1　·　來源：多人實測回饋五項（拍賣／轉介／選職業／按鈕變色／記帳紅綠）

## 你回報的五件事，逐一處理

**1. 拍賣：兩方資訊不同＋沒出價系統就代答** ✅（這期最大的改動）
原本拍賣是「系統替所有對手自動出價、瞬間開標」——你根本沒機會出價，兩邊看到的過程也不一樣。現在是**真人親自密封投標**：有人發起拍賣後，每位真人玩家的畫面會跳出出價視窗（看得到完整卡片，與賣方資訊對等），自己拉出價（0＝棄標）；出價互相保密，**全員出完才開標**，最高價得標、同價取座位序。電腦對手照舊由系統決定論出價。開標前發起人不能先把機會收掉；誰還沒出價，各裝置畫面中央都有「🔨 等你出價」提示條，關掉視窗也叫得回來。系統訊息只會說「某某已出價（保密）」，開標後大家看到同一張結果卡。

**2. 轉介機會：系統自己幫玩家拒絕** ✅
轉介給真人不再由系統代答：對方畫面跳出邀約視窗，**看完整卡片**（入手金額、月現金流、介紹費）後親自按「接受（買下並付介紹費）」或「婉拒」。婉拒不收費；現金不足買不成也不收費。回應前轉介人不能收掉機會，兩邊都有等待／回應提示條。轉介給電腦維持原本的自動評估。

**3. 多人要能自由選職業** ✅
大廳的職業／夢想從小小的下拉選單改成**大按鈕選單**：點「💼 職業」跳出分組清單（含月薪／支出），點「🌈 夢想」跳出夢想清單，點了就選上。自由選、**可以和別人重複**——選單上明寫「朋友局隨意，不是比賽」。

**4. 交易對象選上要變色** ✅
根因：按鈕的「選中」樣式（.act.on）根本沒定義在 CSS 裡，程式有切換但畫面看不出來。已補上——選中的對象、資產、廣播按鈕都會亮金框金字。這一條同時修好轉讓面板、P2P 面板、商城等所有用同款按鈕的地方。

**5. 記帳按鈕紅綠區分** ✅
記帳分類的四顆按鈕照台股慣例上色：**資產、收入＝紅**（好事），**負債、支出＝綠**——一眼分清，不再四顆長一樣。

## 驗證
