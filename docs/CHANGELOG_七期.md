# FinFlow 七期變更說明 — 實測回饋修訂（v1.7.0，2026-08-26）

對應你在 Netlify 實測後回報的 10 項問題。

## 修訂內容

| # | 回報 | 根因與做法 |
|---|------|-----------|
| ① | 還在讀說明就自動開局／操作未完就被自動骰 | 六期的自動擲骰倒數不會偵測視窗狀態。修正：**任何視窗開啟時（開場說明、借款、股市、調參面板、薪資單、決策卡⋯⋯）倒數一律暫停**，關閉視窗後重新從滿額（預設 3 秒）起算。「沒按開始遊戲就開局」實際是說明視窗底下倒數照跑、自動擲骰造成的錯覺，同一修正一併解決。 |
| ② | 設定鈕沒反應 | 真 bug：六期把開關寫成 `classList.add("open")`，但 CSS 定義的是 `.on`，面板永遠滑不進來。已修正並加入自動化測試（開→有內容→關）。 |
| ③ | 系統訊息沒更新 | 兩個原因：股市買進事件沒帶卡片名，一律顯示「你買了『資產』」；且發薪、擲骰等常態動作不進紀錄，畫面看起來停格。修正：買進訊息顯示實際名稱（含股票）；**每次擲骰（含 NPC）都寫入系統訊息**；改為**保留最新 5 則、最新在上、最新一則金色醒目**。 |
| ④ | 地圖太多空位／玩家列太矮／中欄太窄 | 三欄比例 41／19／40 → **37／23／40**；夢想圈加寬到與老鼠圈同寬（176→228）、兩環貼齊，畫布 720→700；玩家動作列最小高度 96→126px、字級同步加大。 |
| ⑤ | 頂列第 N 輪與跑馬燈不需要 | 已移除。輪次與大事紀錄集中在中欄「系統訊息」（六期起就有），頂列只剩 ❔📊⚙ 三鈕。 |
| ⑥ | 操作區結束回合與地圖重複，改結束遊戲 | 操作區主鈕改為「🏁 結束遊戲」：確認後依現況結算排名（自由圈玩家比夢想進度、其餘比淨值）並顯示復盤報告。新增引擎動作 `END_GAME`（進事件溯源、可重放）。結束回合仍在地圖中央。 |
| ⑦ | 夢想圈應該是快樂的 | 八格改鮮明配色：饗食粉紅、山海天藍、旅行紫、傳承金、現金流翠綠、風雲亮橙；實線亮框、未有人在外圈時也保持六成亮度。 |
| ⑧ | 品格太佔空間 | 移除右欄底部的品格星等區塊，改為**數字**緊跟在幸福感之後（例：幸福感 ♥ 2　品格 情緒 1・守法 0・教養 0・孝親 0），滑鼠停留可看說明。 |
| ⑨ | 補繳保證金卻顯示「提前還本」 | 償還 MARGIN（融資）類負債的帳務摘要改為「**補繳保證金：**」，一般貸款維持「提前還本：」。記帳關卡的題目文字隨之修正。 |
| ⑩ | 資產／負債細項要有標頭 | 資產細項加「名稱／現值／月現金流」、負債細項加「名稱／餘額／月付」欄位標頭（無項目時不顯示空表頭）；同時修正兩欄在長名稱＋大數字下會被擠出畫面的排版（固定欄寬＋省略號）。 |

## 假設與備註

- 結束遊戲的結算沿用第 72 輪到期的排名規則；動作寫入 actionLog，同 seed 重放結果一致。
- 自動擲骰倒數的暫停以「畫面上有任何視窗」為準；若你希望改成「按過一次才開始倒數」等其他邏輯，一句話即可調整。
- 夢想圈配色為第一版提案，色票寫在 `renderBoard` 內的 `OUTER_COLOR`，要換色隨時可改。
