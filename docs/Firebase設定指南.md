# FinFlow 多人連線：Firebase 一次性設定指南

適用版本：v2.2.1（M12-A V1）　·　預估時間：10 分鐘，只需做一次　·　費用：Firebase 免費方案（Spark），朋友局規模用不到付費額度

## 為什麼要設定

多人連線需要一個大家的裝置都連得到的「中繼站」來傳遞動作。FinFlow 用 Google Firebase 的 Realtime Database 當中繼站：你在 Google 的網站上按幾個按鈕開好資料庫，把一段金鑰貼進遊戲，之後所有裝置（iPad、NB、手機）都能用 2 碼房號加入同一局。

沒設定金鑰之前，遊戲裡的「同機測試（雙視窗）」仍然可用——同一台電腦開兩個瀏覽器視窗就能互連，適合先體驗流程。跨裝置（NB＋iPad）就需要完成本指南。

## 步驟一：建立 Firebase 專案

1. 用你的 Google 帳號打開 https://console.firebase.google.com
2. 點「建立專案」（Create a project），名稱隨意，例如 `finflow`
3. 問你要不要開 Google Analytics：**關掉**（用不到），然後建立專案

## 步驟二：開啟 Realtime Database

1. 左側選單「建構」（Build）→「Realtime Database」→「建立資料庫」
2. 位置選 **Singapore（asia-southeast1）**——離台灣最近
3. 安全規則先選「鎖定模式」（locked mode）——下一步會換成我們的規則

## 步驟三：貼上安全規則

在 Realtime Database 頁面上方切到「規則」（Rules）分頁，全選刪掉原本內容，貼上下面整段，然後按「發布」（Publish）：

```json
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null && (!data.exists() || data.child('meta/createdAt').val() < now - 86400000)",
        "meta":  { ".write": "auth != null" },
        "setup": { ".write": "auth != null" },
        "lobby": { "$uid": { ".write": "auth != null" } },
        "presence": { "$uid": { ".write": "auth != null" } },
        "log":   { "$seq": { ".write": "auth != null && !data.exists()" } }
      }
    }
  }
}
```

這套規則的意思：只有登入的玩家能讀寫；房間建立後不能被別人整間蓋掉（超過 24 小時的舊房例外——房號只有 00–99 共 100 個，舊房要能回收）；動作紀錄（log）每一格**只能寫入一次、不能改**——這是多人同步不會被竄改的關鍵。這是朋友局等級的保護（知道房號的登入者都能加入），不設計對抗惡意攻擊。

## 步驟四：開啟匿名登入

1. 左側選單「建構」→「Authentication」→「開始使用」
2. 「Sign-in method」分頁 → 選「匿名」（Anonymous）→ 啟用 → 儲存

玩家不用註冊帳號，遊戲會自動匿名登入。

## 步驟五：取得金鑰並貼進遊戲

1. 左上角齒輪 →「專案設定」（Project settings）
2. 往下捲到「你的應用程式」，點 **`</>`**（Web）圖示，暱稱隨意填（例如 `finflow-web`），**不要**勾 Firebase Hosting，按「註冊應用程式」
3. 畫面會出現一段 `const firebaseConfig = { apiKey: "...", ... }`——把大括號那一段（含大括號）複製起來
   - 如果裡面沒有 `databaseURL`，回到 Realtime Database 頁面，把上方那串 `https://xxx.firebasedatabase.app` 網址抄下來，等一下貼完後遊戲會提示缺什麼
4. 打開 FinFlow → 開局畫面 →「🌐 多人連線」→「⚙ 連線設定」→ 把剛才複製的整段貼進框裡 → 儲存
   - 直接貼 `const firebaseConfig = {...}` 原樣也可以，遊戲會自動整理格式
5. **每一台要一起玩的裝置都要貼一次**（金鑰存在各裝置的瀏覽器裡）。最省事的做法：把金鑰貼到你們的群組聊天，各自複製貼上

## 開始玩

- **建房**：一台裝置點「多人連線」→「建立房間」→ 選人數與難度 → 把畫面上的 2 碼房號念給大家
- **加入**：其他裝置點「多人連線」→「加入房間」→ 輸入 2 碼數字
- **大廳**：各自改名字、選職業與夢想 → 按「準備」→ 房主按「🚀 開局」。真人不足的座位由電腦自動補位
- **斷線重連**：頁面關掉或斷網後，重開遊戲 →「多人連線」→「重新連線上一局」，會自動追上進度、座位不變
- **版本一致**：所有人要用同一版遊戲網址（finflow-brian.netlify.app 更新後，大家重新整理頁面即可）

## 本期（M12-A）的已知範圍

- 回合、擲骰、決策、記帳、商城、貸款、破產、勝利判定：全部跨裝置同步
- **資產轉讓**（指定對象或 📢 廣播先搶先贏）與 **P2P 借貸邀約**：已可跨裝置真人對真人親自回應
- 拍賣、合資、轉介遇到「真人對象」時：本期暫由系統自動評估對方意願（下一期 M12-B 開放真人親自出價與回應）
- 電腦玩家由房主的裝置代跑：**房主的視窗要保持開著**，NPC 才會動
- 掛機倒數代打（離線 60 秒由電腦接手、回來可接管）：規劃在 M12-C

## 維護小事

- 玩過的房間會留在資料庫裡（很小，免費額度 1GB 綽綽有餘）。想清就到 Realtime Database 的「資料」分頁把 `rooms` 底下的舊房號刪掉，不影響新局
- 金鑰貼錯或想換專案：遊戲裡「⚙ 連線設定」→ 清除設定，重貼即可
