## 1. 五個功能

### 1.1 商城重複購買 → 灰化，而且引擎真的擋

不是只把按鈕變灰（那只是提示），`E.mallStillActive` 是 UI 與引擎共用的同一份判斷，`MALL_BUY` 動作會直接 reject。三種情況都擋：

| 情況 | 灰化理由 |
|---|---|
| 年約還在效期內 | 「年約還在效期內（至第 N 輪），到期會問你要不要續約」 |
| `oncePerGame` 已買過 | 「本局限購一次，已經買過了」 |
| 保險已投保 | 「已投保，不需重複購買」 |

順帶把旗標機制泛用化（原本寫死 `fitUntil` / `checkedUntil` 兩種），行為與泛用化前逐位元相同（T-46 有專門斷言）。

### 1.2 住宅火險＋地震基本保險（年繳、自動續約）

- **年繳一次扣清**，不進每月支出水位——這是與月繳醫療險刻意做出的對比
- 每 12 輪（`propertyRenewTurns`）**自動續約**，扣得起就續、扣不起就失效
- 理賠 50%（`propertyClaimPct`）：**房產修繕支出**（在水電技能折扣之後）＋**天災事件現金損失**（MA09 強震／MA10 強颱／MA11 土石流，卡片以 `propertyClaim:true` 標記）
- 可隨時解約，但**年繳已付不退**——停掉的是下一次，不是這一次

### 1.3 健檢／健身房年約到期 → 主動問要不要續約

`E.tickRenewals` 掛在回合開始，效期過了推出 `RENEW_MALL` 決策，問一次就不再打擾；續約後效期重算，下次到期會再問。婉拒不扣錢。

### 1.4 高階課程 → 解鎖「特殊機會」牌堆

- **海外碩士留學**（既有 `ML_EDU4`，加上人脈標記）或**新增的 EMBA 在職專班**，任一即解鎖
- 機會格的牌堆選擇多出**第三個按鈕**；沒資格時顯示 **「❓ ？？？」灰色**，副標「有些機會不是靠錢，是靠你認識誰。（尚未解鎖）」
- 新增 `content-mod-special` 內容包，特殊機會 5 張（藥妝店股東／校友商辦／教授實驗室新創／學長物流站／老市場店面）

**定價原則**（量測後定案，見 §3）：門檻高於大額機會、報酬也明顯優於大額機會——花大錢買的入場券必須是真的。

| | 平均年化現金報酬率 | 平均進場門檻 |
|---|---|---|
| 大額機會 | 41.2% | 3,204 |
| **特殊機會** | **53.8%** | **5,575** |

### 1.5 第二專長 → 學成時二選一

新增 3 張 `family=CAREER` 技能（餐飲創業養成班／資料分析轉職營／水電技術士證照班），學成推出 `SECOND_CAREER` 決策：

- **轉職**：薪資與生活支出**整組換掉**（新職業的 salary / baseExpenses / salaryVolatility），原職涯加薪不跟著走，副業一併結束。僅限內圈。
- **兼副業**：`原職 ＋ 副業`。副業是**主動收入**（`INCOME_ACTIVE`）**且每月多一筆時間與器材成本**（`EXPENSE`）——**不計入自由率**，辭職圓夢時收入與成本一起消失。
- **先放著**：學了不動也是一種選擇。

側欄常駐顯示「副業：〈名稱〉　淨 +N／月」並註明「這是主動收入，不計入自由率」。

## 2. 順手修掉的既有缺陷

**年約商品的月費原本是永久支出。** 買一次健身房年約（月費 3）就會每月扣到破產，效期過了也不停；S4 的續約功能會讓它不斷疊加，才把這個問題放大成顯性。現在年約到期時月費一併停止（與 M8 學習期間月費的沖回語意一致）。

同一類錯誤我自己也犯了一次：EMBA 原本設 `recurringMonthly: 6`（兩年課程收一輩子學費），驗收時量到才改成折進一次性學費。

## 3. 驗收過程中量到的四個問題（都已修）

這一階改動橫跨商城、保險、職業、機會牌堆、學習系統五個子系統，第一輪驗收四項不過。**每一項都是量出來的，不是猜的。**

### 3.1 特殊機會比大額機會還差 → 花大錢買到假入場券
第一版定價完全照小額機會的量級（門檻 780～1,300），量出來年化只有 24～32%，而大額機會是 41%。**門檻更低、報酬更差，人脈這個賣點是假的。** 依既有卡牌的價格結構重新定價（RE 20% 自備、BUSINESS profit/price ≈ 2.7%），並用二分法解出達標的租金與獲利。

### 3.2 關閉全部開關後與基線不一致（0/12）
`OPPORTUNITY_SPECIAL` 被加進 `buildDecks` 的牌堆清單後，**即使開關關閉也會多洗一副牌**，`util.shuffle` 消耗 RNG → 後續所有隨機序列位移。改成只有開關開啟時才建置該牌堆。這正是鐵律二存在的理由。

### 3.3 進外圈後仍留著副業
`SECOND_CAREER` 的「兼副業」分支漏了內圈檢查（只有「轉職」有）。已辭職圓夢的玩家還能再開副業，等於辭職沒辭乾淨。

### 3.4 平衡：進圈率一度掉到 22%（−52%）
用逐項關閉的方式拆解出來源：

| 設定 | 進圈率 |
|---|---|
| S3b 基準 | 46.1% |
| S4 全開（第一版） | 22.1% |
| S4 −NPC 保險 | 43.2% |
| S4 −特殊機會 | 38.9% |
| **S4 只剩新內容＋RNG 位移** | **45.3%** ← 內容本身是中性的 |

拆出兩個來源，各自修掉：

1. **EMBA 的永久月費**（見 §2）
2. **我加的 `npc.protectSelf` 讓電腦玩家全體投保**——月繳保費永久壓在自由率的分母上，等於系統性地把所有人擋在自由門檻外。更糟的是我原本的「有餘裕才買」判準寫成 `被動收入 ≥ 支出`，**那正好就是自由門檻本身**：電腦玩家在剛好要達標的瞬間去買月費商品，然後被自己的月費踢回門檻以下。這是我自己造的陷阱。

**最後的處置**：`npc.protectSelf` 是我為了讓模擬走得到產險／續約路徑而加的**測試用裝置，不是你要求的功能**。保險與健康是給真人玩家的選項；讓電腦玩家全體投保會在你沒要求的情況下把難度基準改掉（進圈率約降 6 個百分點）。所以：

- **`npcProtection` 預設 0**——電腦玩家行為與 S3b 完全一致
- 驗收的覆蓋率量測**刻意開成 1**，讓產險理賠、年約續約這些路徑真的被走過
- 想看電腦玩家也投保的樣子，設定面板可以打開
