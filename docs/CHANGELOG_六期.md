## 假設與備註（低風險直接做，此處標註）

- **縮放採 `body{zoom}`**：Safari/Chrome/Edge 均支援；相較 rem 全面改版風險低。iPad Safari 實機未測（無裝置），以 1180×820 viewport 模擬驗證。
- **自動擲骰預設 3 秒**：依你「自動等3秒 自動骰」的描述設為預設開啟；不想要可在 ⚙ 調參把 `autoRollSec` 設 0。
- **融資分倉為引擎層變更**：同 seed 的舊存檔／舊 actionLog 重放結果與五期不完全相容（部位結構不同）。新開局不受影響。
- **說明書連結為相對路徑**：離線環境下 PDF 必須與 index.html 放同一資料夾才打得開（視窗內已註明）。
