## 一、為何下市股價變成那樣（你的第 1 題）

你的畫面同時寫著兩件互相矛盾的事：

> **12,000 / 張　▼100.0%（較上期）**　·　⚠ **已下市，只剩壁紙**

而且線圖不是掉到 0，是**往上噴**到 12,000。

### 根因：一行 `||` 把 0 吃掉了

下市的處理是把價格設成 **0**。但全檔有 **9 處**這樣讀價格：

```js
var price = S.stockPrices[sym] || def.face;
```

`0` 在 JavaScript 裡是 falsy，所以 `0 || 12` 得到 **12**（面額）。介面顯示 ×1000 就是你看到的 **12,000／張**；線圖把「當前價格」接在歷史後面，於是從 ~1,700 一路噴到 12,000。

「▼100.0%」反而是對的——跌幅是拿真正的 0 去算的。**同一個畫面上，跌幅用真值、價格用假值。**

### 而且不只是顯示問題

`TRADE_STOCK` **完全沒有檢查下市**。兩者疊起來的後果（已實跑驗證）：

```
下市後 stockPrices[STK_SPEC] = 0
舊寫法 (||def.face) = 12          ← 12,000/張 的來源
買進已下市股票： ❌ 竟然成功
  花掉現金 120.17　拿到資產 marketValue 120   ← 用面額買到一堆壁紙，帳上還記成有價值
```

**玩家可以用面額買進一檔已經歸零的股票。**

### 修法

抽出唯一的存取入口 `E.stockPrice(S, 股票)`：**面額只在「價格是 undefined（還沒開盤）」時當退路，絕不拿來蓋掉一個真實存在的 0。** 9 處全部改走這個入口，另加 `E.isDelisted()`。

- 引擎層擋下市買進（`DELISTED`）；賣出仍可（就是認賠出場）。
- 機會卡若在手上時才下市，也不得成交。
- 殖利率下市後回 0（原本會用面額算出一個假殖利率）。
- **線圖誠實掉到 0**——那才是這一課該有的畫面。

**為什麼平衡完全沒動**：電腦玩家本來就不會買下市股（`autoBuyUnits` 與 `npc.stockTrade` 都有過濾），所以這個漏洞**只有真人碰得到**。500 局與 5 seed 集因此逐位元相同。

## 二、每輪紀錄改成五欄（你的第 3 題）

依你的 Excel 格式，每一筆事件除了敘述，現在都列出對五個科目的變化：

| 發生了什麼 | 來源 | 現金 | 資產 | 負債 | 收入 | 支出 |
|---|---|---|---|---|---|---|

- 收入＝主動＋被動（每月流量）；支出＝EXPENSE（每月流量）；現金／資產／負債是當次的存量變動。
- **負債與支出增加標成紅色**（對玩家是壞事），其餘增加標綠——顏色跟著「對我好不好」，不是跟著正負號。
- 每一輪多一列 **「本輪合計」**。
- 三個畫面（每輪紀錄／回合結算／戰報）**共用同一份 `ui.ledgerRow`**，避免同一算式寫三份而漂移（S3b、S10 的教訓）。

### 你標註的「賣股票損益似乎有問題」——算式是對的，難讀是真的

我實跑驗證：買 20 張成本 680.2，漲三成後賣出，摘要寫「損益 +200,090」。

```
毛額 884.2　手續費 1.26　證交稅 2.65　實際入袋 880.29
真實損益 = 880.29 − 680.2 = 200.09   ✅ 與摘要一致
```

**數字沒錯。** 你感覺不對是因為五欄裡 **資產 −884.2、現金 +880.29**，兩欄對不起來，而且**兩個數字都不是損益**。已補上說明行：

> 含 券商手續費 1,620、證券交易稅 3,410　·　**現金與資產差 5,030＝交易成本**

這樣不必自己對帳就知道那 5,030 去哪了。

## 三、回合結算彙總畫面（你的第 2 題）

**每輪所有異動完成後，用一個畫面總結，取代零散的小通知。**

- **觸發時機**：你的回合剛結束時。
- **涵蓋範圍**：**上次結算之後的每一筆**——所以在**別人回合發生在你身上**的事（非回合動作、總經全體事件、P2P 期款、股價變動）**一筆都不會漏**。這比「只看自己這回合」完整。
- **內容**：現金淨變動 → 五欄明細表 → 本輪合計 → 結算後的水位（現金／淨值／被動收入／淨現金流）。
- **關閉方式**：一顆 **「朕知道了」**；另有 **自動關閉** 按鈕可在 `不自動關 → 2 → 3 → 5 → 10 秒` 之間循環，按鈕會顯示倒數。
- 沒有任何帳務變動的那一輪**不打擾**。

### 小通知怎麼處理

全檔有 **107 個 toast**。我沒有去改那 107 處（風險太高），而是改在**單一收口** `ui.toast`：

- 結算畫面開啟時，**good／無類別**的通知靜音，改列在結算畫面最下方（「這一輪的提示：…」），**一則都不漏**。
- **warn 類一律照跳**——被拒、追繳、風險警示是需要當下處理的，不能等到回合結束。

### 預設值：不自動關

我把預設設成 **0（只能手動按）**，理由是這個畫面現在是一張要「讀」的表；2 秒關掉等於白做。**你提的 2 秒仍在選項裡**，按一下就切換，設定會記在那台裝置上。前幾輪先不自動關、熟了再開，是我建議的用法。

**關掉之後回得來**：調參面板最上面新增「畫面（本機偏好，不影響對局）」，可以重新開啟結算畫面與調整自動關閉秒數。這兩項是**本機偏好，不進遊戲狀態**，所以不影響決定論與重放。
