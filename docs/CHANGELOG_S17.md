# FinFlow S17 變更說明：主畫面三欄重整
**版本** v2.22.0-S17　**日期** 2026-08-30　**檔案** `FinFlow_S17_index.html`（md5 `024daf70722d930afcf4e02a84d258e4`）

## 一、這一批做了什麼

依渲染稿 v2 與你核定的三點（「1.放中欄最下面 2.留白 3.兩列放四人」）把主畫面改成三欄：

| 欄位 | 由上到下 |
|---|---|
| **左欄** | 總經訊息 → 系統訊息（14 則）→ 玩家卡 2×2 |
| **中欄** | 重大事件警告帶 → 盤面 → 股市資訊／交易所 → **操作區（永遠釘在最下面）** |
| **右欄** | 個人財報（未動） |

### 三點核定事項的落地方式

**1. 操作區放中欄最下面**
`#finBoard` 改成 flex column，`#boardWrap` 吃掉剩餘高度，`#opsBox` 是 `flex:none` 的最後一個子元素。中欄不再整欄捲動——警告帶、盤面、股市、操作區各自定位，所以**操作區不用捲就按得到**（六種解析度實測 `ops.bottom ≤ 視窗高`）。

**2. 沒有重大事件時留白**
警告從「總經區塊裡的一段」升成中欄最上面的獨立帶 `#warnBox`（`min-height:62px`）。沒事件時放一條虛線框「目前沒有重大事件」，**盤面上緣位置不跳動**——這是留白的真正目的，不是美觀。

**3. 兩列放四人**
`#pawns` 從 `repeat(3,1fr)` 改 `repeat(2,1fr)`。四人局用三欄會排成 3＋1，第四張孤零零占一列。

### 順手處理的兩個版面缺陷

**擲骰鈕壓到「底層牛馬區」**
盤面縮進中欄後內圈的洞變矮，原本壓在洞上緣的兩行字被擲骰鈕蓋住。改成：
- SVG 的兩行字釘在洞的**下緣**，上半留給 `#boardCenter`
- `renderBoard` 輸出一個看不見的 `<rect id="boardHole">` 當定位錨
- 新增 `ui.placeBoardCenter()`，量 `#boardHole` 的實際矩形把中央那疊釘進洞裡（取代原本的 `top:40%` 百分比定位——百分比會隨解析度飄）
- 骰子 62→52px、擲骰鈕縮一號，讓內容塞得進洞

**操作區三顆小圖示壓到按鈕**
`#opsIcons` 原本是 `position:absolute`，會疊在「自動執行」上緣。改成新的 `#opsHd` 標題列，標題與圖示同一列 `space-between`。

## 二、未預期發現（不得靜默處理）

**（A）`body{zoom}` 讓 `getBoundingClientRect` 與 inline style 不同單位——這是第一版寫錯的地方**

專案在 ≥1440px 用 `body{zoom:1.12}`（級距共五段：0.9／1／1.12／1.28／1.5）。`getBoundingClientRect()` 回的是**乘過 zoom 的螢幕像素**，但寫回 `style.left/top/width` 是**還沒乘 zoom 的版面像素**。我第一版直接搬，結果 `#boardCenter` 整個大 12%、位置也偏，量出來 `bc 391.5×123.2` vs `hole 349.6×110`——正好差 1.12 倍。

修法是把倍率**量出來**而不是寫死：`sc = wrap.getBoundingClientRect().width / wrap.offsetWidth`。T-93 有一條專門擋「有人回頭寫死 1.12」。

**（B）我自己的捲軸量測方法錯了，差點誤報一個不存在的缺陷**

第一次用 `document.body.scrollWidth > window.innerWidth` 判斷水平捲軸，1024×768 報 SCROLL-X。實際上 `scrollWidth` 是**未乘 zoom 的版面像素**（1138），`innerWidth` 是螢幕像素（1024），1138×0.9＝1024——兩者本來就不同單位。改用 `window.scrollTo(9999,9999)` 後看 `scrollX/scrollY` 是否 >0，**六種解析度全部無水平也無垂直捲軸**。這條記下來：以後量捲軸不要拿 scrollWidth 跟 innerWidth 比。

**（C）`ui.render` 末端才對位**
`renderBoard` 內部呼叫 `placeBoardCenter()` 一次不夠——當下中欄其他區塊還沒畫完，`boardWrap` 的高度之後還會變，量到的是舊幾何。所以 `ui.render()` 末端再對位一次，另外掛 `resize` 監聽。
