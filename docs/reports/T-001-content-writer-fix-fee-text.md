# T-001 content-writer 修正：新股抽籤手續費文案（第二次修改）

## 結論
- `manual/rulebook.html` §8.10「申購」列把「處理費（2%）／中籤通知費（5%）」改為固定金額「處理費（20 元）／中籤通知費（50 元）」，並加一句提醒兩筆都是固定金額、不隨申購價變動。
- `manual/quickstart.html` 新股抽籤 tip 原本只寫「申購價＋手續費」「手續費不退」，語意含糊、容易被誤讀成比例費用；已改寫為明確的「處理費 20 元＋中籤通知費 50 元（固定金額）」，並修正「沒中」的退款描述為「退回申購價與中籤通知費（處理費不退）」，與 rulebook 結算段一致。
- 已依 ADR-001 D4 核對：`ipoFee`＝0.02 千元（20 元）、`ipoNoticeFee`＝0.05 千元（50 元），均為固定金額，不隨 `P`（申購價）等比例變動；沒中退「申購價＋通知費」、處理費不退，中籤結算用上市價，兩份文件現有敘述與此一致。
