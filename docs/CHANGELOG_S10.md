## 1. 怪符號：這是我上次沒修乾淨，不是新問題

### 根因

檔案裡有**三個** `el()` 函式，各自包在一個 IIFE 裡（所以不會互相覆蓋，各管各的區塊）：

| 位置 | 負責的畫面 | S9 以前的狀態 |
|---|---|---|
| L5986 | 決策卡、主畫面 | ✅ S3b 修過，會處理 `<b>` / `<br>` |
| **L9097** | **側欄面板、借款視窗、規則說明** | ❌ 仍是 `textContent` |
| **L13490** | 多人大廳 | ❌ 仍是 `textContent` |

你截圖的借款視窗在 L13391，走的是 L9097 那一個——所以 `年利率 7.00%<br>` 被原樣印出來。**S3b 我只改了第一個就宣稱修好了。**

### 為什麼測試沒抓到（這件事比 bug 本身嚴重）

S3b 當時寫的 T-44 其實有一段渲染驗證，長這樣：

```js
if(typeof document!=="undefined"){
  var e1=el("div",null,okCases[0]);
  assert(e1.textContent.indexOf("<b")<0, "可排版字串不得留下字面標籤");
  ...
}
```

`selftest_run.js` 是 headless、**沒有 `document`**，所以這段從第一天起就沒執行過。測試「通過」不是因為它驗過了，是因為它沒跑。這是我自己給自己開的後門。

**先修測試**：`selftest_run.js` 掛上 jsdom 的真 DOM。掛上去之後，**還沒改任何程式碼**，跑在當時的出貨版 S9 上：

```

```

這條測試一直有能力抓到，只是從來沒被叫起來。

### 修法

`el` 只留一份實作，掛成 `ui.mkEl`；另外兩個區塊改成 `var el = ui.mkEl;`。危險標記（`script` / `img onerror` / `a` / `iframe` / inline style）的白名單防線原樣保留。

新增 **T-62**：斷言 `el === ui.mkEl`，並用**截圖上那一句的實際形狀**去驗渲染結果：

## 2. 隱藏機會：未解鎖也要有金框，問號放大

原本整顆按鈕 `opacity: 0.45`，看起來像**壞掉的列**，而不是「還打不開的門」。

改成新的 `.opt.locked` 樣式：金色虛線外框、右上角 `🔒 待解鎖` 標記、問號放大到 1.9em 並加金色光暈。副標也從只說「尚未解鎖」改成寫明**怎麼解鎖**：

> ❓ ？ ？ ？
> 有些機會不是靠錢，是靠你認識誰。修 EMBA 或海外留學就能打開這扇門。

「你還打不開」跟「這裡沒東西」是兩件事，畫面上要分得出來。原始碼層檢查一併釘住金框樣式、套用處、放大問號三者都在，而且不得再用整顆 `opacity`。

## 3. 股市開盤價依開局而不同

原本 `E.newGame` 是 `S.stockPrices[s.symbol] = s.face`——**每一局都從面額開始**。而 `clampPrice` 的上下限也是以 `face` 計，所以玩家玩久了知道面額在哪，就等於知道地板在哪，「跌到 −90% 應該離底部不遠」變成可以背的規律。

改成每局在面額上下隨機開盤：

```js
var openSpread=E.cfg(S,"stockOpenSpread"); if(!isFinite(openSpread)||openSpread<0) openSpread=0;
C.stockDefs.forEach(function(s){
  var px=s.face;
  if(openSpread>0){
    var f=1 + (util.rand(S)*2-1)*openSpread;
    px=E.clampPrice(S, s, s.face*f);
  }
  S.stockPrices[s.symbol]=px;
});
```

新增設定 `stockOpenSpread`（預設 **0.25**，即面額 ±25%）。`stockHistory` 的起點同步改為開盤價，否則第一期的「較上期」會算成相對面額的漲跌。

`spread=0` 時**完全不取用亂數**，所以關掉之後與基線逐位元一致（鐵律二）。

註：股票的顯示名稱本來就已經每局隨機（`NAMEPOOL`），這次補上的是價格。

## 5. 未預期發現

1. **「有 DOM 才驗」的條件式測試等於沒有測試。** 這次是 `if(typeof document!=="undefined")`，但同一個形狀可以出現在任何地方（`if(有網路)`、`if(檔案存在)`）。往後任何條件式跳過的測試，要嘛把條件補起來讓它一定會跑，要嘛就不要寫——寫了卻不跑比沒寫更糟，因為它會讓人以為驗過了。
2. **同一個功能寫三份，只改一份卻宣稱修好**，是 S3b 那次的真正教訓。原始碼層的單一實作檢查現在補上了，但只涵蓋 `el`；檔案裡是否還有其他「同名不同份」的函式，尚未全面盤點，標 **UNKNOWN**。
3. 開盤價隨機會位移整個亂數流，所以 T-61 的數位資產開張率從 33.3% 變成 34.4%、本行／外行的分佈也跟著動。這是預期內的 RNG 位移，不是行為改變——`stockOpenSpread=0` 時完全復原可以佐證。
