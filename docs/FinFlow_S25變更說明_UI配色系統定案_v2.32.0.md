# FinFlow S25 變更說明——UI 配色系統定案（v2.32.0-S25）

對應文件：《UI配色優化工程規劃書_定案版 v2.0》（Brian 提供，與 PM 多輪對稿後的定案版）＋本輪審閱／討論的六項確認決定＋三版視覺示意圖（v5 校正版／v6a 抵達感加強版／v6b 退回整塊金色版，最終定案＝v6a 再加濃一階）。

範圍：**僅色彩**，不動版面資訊架構（三欄式排版、卡片位置、元件功能、棋盤格數與排列維持不動）。

## 一、為什麼要做這批

規劃書的共同目標：讓玩家能在 1 秒內用顏色分辨「這是警告」「這是可操作按鈕」「這是財報正負向」，並讓棋盤格的視覺語言更貼近遊戲情境——牛馬圈（努力打拚階段）與夢想圈（財務自由後）用底色與格子色調做出情緒對比。

## 二、審閱階段抓到的落差（規劃書 vs 實際引擎）

規劃書是在另一個對話串定稿的，動手前先對照本репо的實際渲染程式碼（`ui.renderBoard`／`CELL_COLOR`／`OUTER_COLOR`）逐項核對，抓到以下落差，都在動手前先跟 Brian 對過：

1. **色盲友善設計會被推翻**：現有 `--pos/--neg` 特意選用藍綠／橘紅並在程式碼註解自陳「色盲友善」；新規格為貼近台灣「紅漲綠跌」「紅字虧損」慣例，同畫面會同時出現三種紅綠語意。Brian 確認：**主動放棄色盲友善**，接受這個取捨。
2. **`--pos/--neg` 實際使用範圍遠大於規劃書設想**：程式碼裡這兩個 token 至少在 20 幾處用於財報以外的情境（商城可負擔判斷、期貨追繳警示、技能前提、冷錢包狀態、成就徽章、通用 ok/fail）。Brian 確認：**只對主畫面呈現有想法**——最終做法是用 `[data-tut="fin"]` / `[data-tut="detail"]` 屬性選擇器把新色彩鎖定在損益表／資產負債表／資產與負債細項這兩個固定可見的容器內，容器外的 `--pos/--neg` 完全不動。
3. **牛馬圈／夢想圈一開始誤判要補「發薪／現金流」格**：查了 `E.buildBoards` 才發現 `fixedPayday` 這個開關**預設值是 1（開啟）**——S14b 就把「發薪」改成每輪自動結算，不再靠走到發薪格觸發，這兩格因此在正常遊戲根本不會出現（engine 會自動把它們換成機會/市場/人生/生活與風雲）。**這是 Brian 在看過 v5 校正版之後親自抓到、我上一輪查得不夠深的錯誤**——原本已經生出兩版含發薪／現金流色的示意圖，後來全部撤掉，只在 CSS 註解留一句話說明這兩色僅供 `fixedPayday=0` 舊制相容，不進主要配色系統。
4. **夢想圈色彩最初誤判要擴成 8 色**：一開始把 S24 剛擴充的 8 個夢想標題（星辰／店鋪／峰頂／深潛／大陸／航行／校園／傳承——玩家選了某個夢想後抽 milestone 用的內容池）跟棋盤上夢想圈格子本身的分類搞混。實際上棋盤格子分類固定是 6 種（風雲/饗食/山海/旅行/傳承/現金流，對應引擎 `OUTER_COLOR`），跟玩家選哪個夢想無關；扣掉第 3 點的「現金流」，落地的是規劃書原本就有的 5 色，不需要擴充。
5. **夢想圈金色背景的「風險」判斷一開始說反了**：以為要動到版面容器結構，後來讀到 `ui.renderBoard` 才發現 SVG 裡本來就有一段獨立畫夢想圈背景的 `<rect fill="url(#dreamBg)">`（原本是靛藍漸層），换色其實只是換兩個 gradient stop-color，風險很低。Brian 看了 v5（暗底較淡）、v6a（暗底金暈加濃）、v6b（退回規劃書原本的整塊亮金漸層）三版後選 **v6a 再加濃一階** 定案。
6. **主要按鈕（結束回合／借款／還款）**：規劃書要求改用電光紫 `--brand-primary`，Brian 確認**維持現有金色漸層不換**，理由是遊戲的金融致富調性一直靠金色撐場面。電光紫這次沒有引入任何新用途（沒有新增選取棋格外框或進度條的紫色元件），純粹按兵不動，留給下一批要不要用再議。

## 三、實際落地的改動

### 3.1 財報語意色（範圍限定）
- 新增 token：`--fin-gold:#F0C24B`（沿用既有 `--gold` 同色）、`--tw-red:#FF4D4D`、`--stock-down:#2FBE72`。
- CSS：`[data-tut="fin"] .pos,[data-tut="detail"] .pos{color:var(--fin-gold)}`／`[data-tut="fin"] .neg,[data-tut="detail"] .neg{color:var(--tw-red)}`——只在損益表／資產負債表（`fin`）與資產細項／負債細項（`det`）這兩個右欄固定容器內生效。
- 容器外的 `--pos/--neg`（商城、期貨、技能門檻、成就徽章、股票/期貨個別標籤色…）**完全沒動**，維持原本的藍綠/橘紅。

### 3.2 主畫面股市漲跌色
- 只在 `uiCore.js` 一處加了一個 `chg` class（原本的 `▲▼` span，`"ch"→"ch chg"`），CSS 加 `.chg.pos{color:var(--tw-red)} .chg.neg{color:var(--stock-down)}`。
- 同一清單裡期貨的「溢價／折價」欄用的也是 `.ch` class，但沒有 `.chg`，刻意不套用紅綠——溢價/折價不是漲跌方向，套用會誤導。單檔股票detail 頁的 ▲▼（`ui.showStockPanel`）也沒有動，維持舊色——那是子頁面，不在「主畫面」範圍內。

### 3.3 棋盤：牛馬圈五色＋夢想圈五色＋統一鍍金框光暈
- 內圈（`CELL_COLOR` 對應的既有 CSS 變數，只換色碼不換變數名，降低牽動面）：機會 `--opp:#A78BFA`、生活 `--life:#5B9BD8`、市場 `--mkt:#4ABBA0`、人生 `--evt:#D98A4C`、失業 `--lay:#E0708A`。發薪 `--pay` 未動（僅 `fixedPayday=0` 舊制會用到）。
- 外圈（`OUTER_COLOR`，JS 內硬編 hex，因為原本就不是走 CSS 變數）：風雲 `#6E56C8`、饗食 `#D9622F`、山海 `#2F9E82`、旅行 `#3488D9`、傳承 `#8C3B4A`（文字改暖米白 `#FBEFD6`，其餘白字）。現金流 `OPAYDAY` 未動。
- `cellRect` 改寫：所有格子的邊框統一改成金色（`#F0C24B`），不再各自用分類色當邊框；新增 SVG 濾鏡 `goldGlow`（內圈）／`goldGlowStrong`（外圈夢想圈，光暈更強），格子文字統一改白字（傳承格例外用暖米白）。原本內外圈文字顏色＝背景色的舊寫法（可讀性較低）一併淘汰。

### 3.4 夢想圈底色
- 原本的靛藍線性漸層 `<linearGradient>` 改成暗底＋濃金放射漸層 `<radialGradient>`（中心 72% 不透明度的金色，往外過渡到近黑），分隔線與外框都改金色，「夢想圈」標籤字改金色（原本是淡紫色）。夢想圈格子的 fill-opacity 也從 0.26/0.45 提到 0.36/0.55，整體更有「抵達感」，對應 Brian 選定的 v6a 加濃版。

### 3.5 沒有動的部分（刻意，不是漏做）
- 系統警示色（景氣燈號／央行升息／危機倒數）與品牌互動色（電光紫）——規劃書「六、導入順序建議」的 Step 2，這次沒有實作。這兩個概念在規劃書裡對應的畫面（總經訊息區塊、選取棋格外框、進度條）跟目前遊戲的實際結構還沒有逐一核對過，為了不要在沒核對清楚的狀況下亂改，這批先不碰，留待下一批單獨核對後再做。

## 四、測試與驗證

- `node tests/runtests.js` → 95/95 通過（純色彩/渲染改動，沒有動到 reducer 邏輯）。
- `node tests/gate.js` → 1000 局壓力測試乾淨（`NaN:0 Infinity:0 invalidGames:0 assetLedgerMismatch:0`）。
- 用 Playwright 實際開一局、注入資料，截圖核對：財報數字金/紅、股市▲▼紅、棋盤牛馬圈/夢想圈五色＋金框光暈、夢想圈暗底金暈——全部與定案的 v6a（加濃版）示意圖一致，讀回截圖比對過。
- 未跑鐵律四（關閉開關比對 S22 基線）的 MD5 雜湊比對——這批是純渲染/CSS 改動，沒有動到任何 `E.*` reducer 函式或 RNG 呼叫，理論上不影響狀態，但**沒有實際跑那道比對**，這裡誠實標注，若要嚴謹起見可以另外補跑。

## 五、未預期發現

1. 過程中兩次自我更正（見上方第三、五點）並非藏著不講——第一次（發薪/現金流格）是 Brian 親自抓到、我沒查夠深；第二次（夢想圈背景風險判斷）是我自己補查程式碼後發現判斷錯誤，兩次都在動手前攤開講清楚，沒有將錯就錯。
2. `--life` 這個 CSS 變數目前身兼兩用：棋盤「生活」格顏色，以及股市清單裡迷因幣標籤（`CRY_MEME`）的顏色——這次把 `--life` 從紫紅 `#B45FD0` 改成藍色 `#5B9BD8` 後，迷因幣標籤的顏色也會跟著變。影響很小（只是一個小標籤色），但這是原始程式碼就有的雙重用途，不是這次新增的問題，這裡列出來避免之後被誤認為新 bug。
3. 系統警示色與品牌互動色（電光紫）這次刻意沒做，已在上方 3.5 明確列出，不是漏做。
