## 一、三個設計決定，都有理由

### 1. 不畫假面板——直接在真畫面上疊熱點

原本可以用 HTML/CSS 畫一張「長得像遊戲」的假面板，前期比較快。**沒有這樣做**，因為這個專案的版面三天內改過三次（S14a、S17、S18），靜態圖一定會過期，而且**過期不會有人發現**。

實際做法：跑一局固定種子的示範局，用**真正的 renderer** 畫出來，再把熱點疊上去。熱點綁的是 DOM 錨點（`id` 與新加的 `data-tut`）不是座標，所以版面改了熱點自己跟著跑。

為了讓錨點穩定，在 `renderFinBoard` 與 `renderSheet` 加了 7 個 `data-tut` 標記（macro／syslog／stocks／exchange／credit／fin／freedom／learn／detail／holdings）。純標記，不影響版面。

### 2. iPad 沒有 hover——一律點一下出說明

Safari 在觸控裝置上會把第一次點當 hover、第二次才算 click，只靠 hover 等於不能用。所以熱點畫成**看得見、點得到的編號圓點**，不做透明大區塊（觸控會誤觸，而且看不出哪裡可以點）。桌機的 hover 只是附加。

### 3. 教學在 iframe 裡載入自己——不會洗掉你正在玩的局

如果你在第 23 輪按 ❔，教學不能把你的局蓋掉。做法是開一個 overlay，裡面用 `<iframe src="自己#tut">`；子層偵測到 `#tut` 就跳過開局流程，直接起示範局並畫熱點。

實測過 `file://` 下 iframe **載得起來**，但父層**讀不進子層**（opaque origin，跨層存取丟 TypeError），所以熱點一律畫在子層、父層只負責裝框與關閉鈕。單機、GitHub Pages、隨身碟三種情境都成立。

**隔離性有測**：從第 42 輪按 ❔ 進教學，玩家的局 turn 42→42、seed 不變。

第二層的五個會**先幫你把那個面板打開**再標熱點，離開時自動收掉。

### 卡片格式：三段，每段一句話

```
⑰ 記帳盤面
這是什麼   把這回合的錢分到資產／負債／收入／支出四格。
時機       每回合結束前，標準難度以上都要做。
⚠          整筆全對連續 5 次才解鎖自動記帳，錯一格整筆歸零。
```

長度有自我測試守著：`what`／`when` 各 ≤40 字、`warn` ≤48 字。寫太長測試會紅。

### 兩種模式

- **一步一步帶**：預設。上一步／下一步走完 20 步，第二層會自動開關面板。
- **自由點**：15 顆編號圓點同時顯示在真畫面上，想查哪裡點哪裡。

### 常駐的「⚠ 會害你輸的七件事」

1. **幸福感沒到 10 點不算贏**——錢做滿了也沒用，這是最多人栽的地方
2. 人生商城只能自己回合買，每一輪一件
3. 淨現金流是負的時候，融資閘門會直接擋住你
4. 投機股是四檔裡唯一會下市歸零的
5. 夢想點數越買越貴：第 n 點 175,000 × n 元
6. 夢想圈現金變負只能急售自救 2 次
7. 記帳要整筆全對連續 5 次才解鎖自動

## 三、順手修掉的缺陷

**❔ 面板裡的 PDF 連結在網站上是 404。** 原本寫的是同層相對路徑 `FinFlow_快速上手指南.pdf`，但 repo 裡 PDF 在 `manual/`，所以從 GitHub Pages 或 Netlify 玩的時候兩條連結都打不開。改成同時給「網站版」（`manual/…`）與「同資料夾版」兩個連結，並寫明什麼時候該點哪一個。

## 四、踩到的坑（不得靜默處理）

**自由模式一開始整片全黑。** 高亮框用 `box-shadow: 0 0 0 9999px rgba(...)` 把畫面壓暗，導覽模式一次只圈一塊沒問題；自由模式同時圈 15 塊，**遮罩疊加**就變成全黑。

修法是把壓暗那層拆成 `.tutRing.solo`，只在導覽模式用；自由模式改成細的金色外框。`s20test.js` 有一條專門擋這個：自由模式下 `.tutRing.solo` 的數量必須是 0。

**另一個**：錨點貼齊畫面邊緣時（左欄從 x=0 開始），圓點放在「錨點左上角 −13px」會跑出畫面。改成夾回可視範圍。實測第一版有 7 / 20 步的圓點看不到。
