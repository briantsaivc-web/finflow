# FinFlow 九期變更說明 — 利率、通膨與全服公告（v1.9.0，2026-08-27）

## 修訂內容

| # | 需求／回報 | 做法 |
|---|-----------|------|
| ① | 貸款大部分要用浮動：基準＋加碼 | 新增設定 `floatingByDefault`（預設開）。**所有新貸款（信貸、房貸、企業信貸、融資、紓困）與開局既有負債（含就學貸款）一律機動計息**：利率＝基準＋商品加碼＋信用評級加碼。商品加碼改為「承作當時的利率減去當時基準」並存進負債本身，央行升息時每一筆浮動貸款同步重定價、月付跟著變。唯一能鎖固定的仍是**轉貸**（付 1% 手續費），這讓轉貸第一次有了真正的取捨。 |
| ② | 支出要隨通膨調整（12 輪一年調一次） | 原本是「景氣一換檔就調一次物價」，時點不規則。改為**年度物價調整**：每滿 `inflationTurns`（預設 12 輪）依當時景氣的通膨率調一次生活支出與房產租金，中欄總經訊息顯示「下次物價調整 N 輪後」倒數，調整當下發全服公告。 |
| ③ | 貸款卡加入原始金額／已還期數 | 貸款卡新增：**原始貸款金額（第 N 輪起貸）**、**本金餘額（已還本金 X%）**、**已還期數 M 期／共 N 期**，浮動貸款另外拆解顯示「基準 x% ＋加碼 y%」。負債物件新增 `originalPrincipal`／`startTurn`／`periodsPaid`，每期攤還時累加。 |
| ④ | **Bug：選擇還款沒有記帳、帳目不平、錢扣了債還在** | 真 bug，根因在記帳題目的建立時機：`buildBookkeeping` **只在擲骰落點結算時建一次**，之後在 READY_END 做的還款／買賣／借款完全不會產生記帳題目。所以玩家在記帳關卡只看得到現金那半邊、負債那半邊沒出現，看起來就是「錢扣了、債還在」。修正：記帳題目改為**可重建**（以 `entryId#posting` 為鍵，保留已答對的題目），並掛進 `syncPhase`，回合中任何自主動作都會補上對應題目。<br>另外已驗證引擎端帳務本來就是平的（現金 −N、負債 −N、分類帳累計＝負債清單），新增 T-21 永久鎖住這個不變式。 |
| ⑤ | 玩很多輪也沒有重大事件的預告與發生 | 黑天鵝機率 3%／輪 → **6%／輪**，並新增 `shockGuaranteeTurn`（預設 26）：到該輪仍未出現過系統性衝擊就**必定預告一次**，確保「預告 → 倒數 → 衝擊」這堂課一定上得到。預告、倒數、衝擊三個階段都有全服公告與中欄倒數。 |
| ⑥ | 跳到夢想圈的玩家定位不正確 | 兩個原因：<br>(a) 七期把夢想圈加寬到與老鼠圈等寬後，兩環**在視覺上連成一片**，看起來像沒換圈；<br>(b) 棋子的橫向錯位是用「全體玩家索引」算的，**獨自站一格的棋子也被推開十幾 px**。<br>修正：夢想圈左右內縮並加上**獨立底板（紫藍漸層圓角面板）＋虛線分隔線＋加大標題與說明**，與老鼠圈明顯分區；棋子錯位改為只跟**同一格的人**錯開（實測貼齊誤差 ≤6px），外圈也加上「目前所在格」高亮。 |
| ⑦ | 進夢想圈與夢想進度應發全服公告 | 新增全服公告橫幅（畫面上方滑入、點一下關閉、數秒自動收）。觸發事件：**辭職進入夢想圈**（含夢想名稱與所需點數）、**夢想進度推進**（第幾點／還差幾點／是否為聖地免費）、**黑天鵝預告與衝擊**、**破產出局**、**年度物價調整**。 |

## 假設與備註

- 浮動改為預設後，`REFINANCE`（轉貸）仍會把該筆鎖成固定利率——保留這個策略選擇。
- 年度物價調整取代了原本的「換檔即調價」，所以同一局的物價調整次數變得可預期（72 輪約 6 次）。
- 黑天鵝仍只在景氣為復甦／過熱時預告（衰退中再來一次衝擊過於殘酷），保證輪次到了才會強制觸發。
- 記帳題目重建掛在 `syncPhase`：還款後若有未分類題目，會**立即**進入記帳畫面。若你希望改成「按下結束回合時才一次結算」，可以調整（目前這樣做是為了確保事件溯源可重放）。
