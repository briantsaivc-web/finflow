## 假設與裁決（低風險細節，直接做並標註）
1. 草圖骰子畫在夢想圈下方；實作放在老鼠圈中央（互動主場，也與現行擲骰動線一致）。
2. 行內買賣為**現股**；融資下單仍走「進階下單」（原股市 modal）——行內按鈕不適合帶風險確認流程。
3. 行內［賣］以市價（含景氣倍率）快賣並自動清償連結貸款；增貸/轉貸等進階操作點資產名稱進原視窗。
4. ［還］開既有還款視窗（還款需要輸入金額，不適合單鍵）。
5. 草圖「交易所」的 P2P 借款/JV 邀請為常駐面板；現制 NPC 即時應答、無「待處理邀請」狀態，故此區顯示**進行中部位**，發起動作在操作區「交易所」鈕（原交易面板含 P2P 頁籤）。
6. 玩家動作列狀態值：你的回合/思考中/等待/停走 N 輪/破產出局＋現金。
7. 決策卡維持置中 modal（未在草圖中另行指定）。
