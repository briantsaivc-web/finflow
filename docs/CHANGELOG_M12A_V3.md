# FinFlow 變更說明 — 多人連線實測 V3 修訂 v2.3.0

日期：2026-08-27　·　基底：v2.2.2　·　來源：多人實測回饋六項（P2P 帳務／廣播借款／比賽擲骰／合資／退出機制）

## 你回報的六件事，逐一處理

**1. P2P 帳務要分本金與利息（利息屬被動收入）** ✅
你說得對，原本兩邊都只記現金進出，看不出本利結構。現在：**放款人**的 P2P 債權掛「當期利息」為每月被動收入（會隨本金攤還逐期遞減，清償歸零）——民間放款的利息正式計入你的被動收入，**會幫你達成「被動收入 ≥ 支出」的自由條件**；**借款人**的每月月付計入支出流，清償後移除。每期帳目明寫「本金 X＋利息 Y」。連帶抓到一個潛在漏洞：P2P 原本可以走銀行式「提前還本」，但錢不會進放款人口袋（憑空消失）——已封鎖，民間借貸一律按期攤還給對方。

**2. P2P 借款要能發給所有人，玩家拒絕後要問 NPC** ✅
借款模式的對象多了「📢 所有人（先答應先成交）」：所有真人畫面跳出放款邀約（載明金額、利率、每期回收），第一位答應的成交；**真人全婉拒後自動輪詢電腦**——水位夠、且你開的利率達到它要求下限的第一位 NPC 就放款；連電腦都不肯，會明講原因（利率太低或大家現金吃緊）。你說的「用 12% 問過玩家再問 NPC」就是這條流程。

**3. 商城比賽要由玩家親自擲骰** ✅
報名（付費）後不再直接告訴你結果——會跳出比賽卡：列出各點數對應的名次與獎金，**你自己按「🎲 擲骰！」**，擲完全場公告點數與名次。電腦或離席代打則自動擲。

**4. 合資：對方資金夠卻被判不足＋要能廣播** ✅
抓到根因：真人夥伴被套用了 NPC 的「現金水位規則」（現金要 ≥ 出資額＋3 個月支出才肯），你朋友現金夠出資、但沒過水位線就被系統代拒了。現在**真人夥伴改為親自回應**：對方畫面跳出合資邀約（完整卡片＋你倆的出資與月現金流試算），現金夠出自己那份就能答應——水位規則只留給電腦用。同時加上「📢 所有人（先答應先合資）」廣播：真人先搶，全婉拒才輪詢電腦。這也一併回答了第 6 點——**合資不再由系統代答**，五種互動（轉讓、P2P、拍賣、轉介、合資）現在全部真人親答。

**5. 玩家可退出、由 NPC 替代；房主退出怎麼辦** ✅
- **任何玩家**：畫面下方的按鈕（非房主原本是灰的）現在是「🚪 離開本局」——確認後座位交給電腦代打，遊戲繼續；正在等你回應的報價／出價／邀約會自動以「婉拒／棄標」結掉，不會卡住別人。之後隨時「多人連線 → 重新連線上一局」**回來接手**，全場會看到「👋 回來了」。
- **房主退出**：不會全部結束——房主按鈕改為二選一：「🏁 結束遊戲（全員結算）」或「🚪 只有我離開」。選離開時**房主自動交棒**給下一位真人（對方畫面會出現「👑 你接任房主」，電腦玩家改由他的裝置代跑）。若房裡已沒有其他真人，這一局暫停保留在雲端，任何人重新連線即可續玩。

## 驗證

- 引擎自測 **33/33**：新增 T-32 鎖住全部新行為——本利分流（利息＝被動收入、月付＝支出、逐期遞減、清償歸位、帳目對轉）、P2P 提前還本封鎖、廣播借款真人優先與 NPC 遞補、合資親答（含重現你回報的誤判情境：夥伴現金低於舊水位線但夠出資 → 現在成立）、廣播合資、離席代打（含拍賣自動棄標開標）與回來接手、原生 NPC 座位不可被接管。
- T-24 比賽測試改寫為兩段式（報名→親自擲骰→同 seed 同點數可重放）。
- smoke15 多人端對端 15 項全過（第 7 項改測「離開本局」新按鈕）；單機 smoke、smoke7–14 全過。
