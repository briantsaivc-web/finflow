# FinFlow 變更說明 — 多人連線實測 V4 修訂 v2.3.1

日期：2026-08-27　·　基底：v2.3.0　·　來源：多人實測回饋十二項

## 最重要的：NaN 連鎖 Bug ✅

根因抓到了：v10 新增的不動產卡有 **6 張漏填 `monthlyCost`（每月持有成本）**——「新莊工業宅兩房」等 4 張小額卡＋2 張大額卡。買到任何一張，月租金淨額算出 NaN，被動收入跟著 NaN，之後整張報表（淨現金流、自由進度）全部 NaN。三層修法：

1. **資料補齊**：6 張卡全部補上 monthlyCost（約月租的 12%，與原始卡片同一比例）。
2. **引擎防禦**：買入計算全面加上缺欄位保護，就算未來卡片有洞也不會再產生 NaN。
3. **防線入測**：新增 T-33「內容數字體檢」——每張卡的關鍵數字必須有限、小額每張 RE/BZ 卡實際買一遍驗證零 NaN。這個測試寫完當場又抓到 2 張大額卡同樣的洞，證明值得。

你手上 NaN 的那一局：更新後重新整理，重放時會用補好的卡片資料重算，數字自動恢復正常。

## 其餘十一項

**復盤誤解為毀棋** ✅　「復盤」按鈕在遊戲進行中直接隱藏，終局時本來就會自動跳出復盤報告，結束後按鈕才出現。

**「準備」按鈕加大鮮明** ✅　大廳的準備鈕改成大顆金色「✋ 我準備好了！」，按下後轉為「✅ 已準備」。

**放款也要廣播** ✅　「我要放款」也有「📢 所有人（先答應先借到）」：真人畫面跳邀約（含銀行利率更低的提醒），先答應的人借到；全婉拒輪詢電腦——但電腦維持理性：只有銀行額度用罄的 NPC 才接民間資金，沒人要會明講。

**廣播借款上限＝他人現金最大值的 50%** ✅　滑桿上限即時鎖住，引擎同步驗證（超過直接拒絕）。

**交易所顯示 P2P 關係** ✅　P2P 面板頂部新增「進行中的民間借貸」一覽：誰 → 誰、餘額、年利率、月付，全場的每一筆都看得到。

**小額機會去掉股票卡** ✅　10 張股票卡從小額牌堆移除（封存保留供舊紀錄重放，不會再被抽到）；想買股票走「股市」面板。平衡重跑 200 局：局長中位 56 → 52（−7%）、跌落率 12%——牌堆變純現金流卡後節奏略快，都在 ±20% 容許帶內；若你覺得太快，下一版可微調。

**比賽擲骰 0.5 秒動畫** ✅　按下「🎲 擲骰！」骰面轉動半秒才開結果，全場公告點數與名次。

**轉介卡怪字** ✅　根因：說明文字用純文字模式塞了 HTML 標籤，`<br>`、`<b class='gold'>` 被原樣印出來。已改為正確渲染。

**轉介也要廣播** ✅　轉介面板第一顆按鈕就是「📢 轉介給所有人（先接受先成交）」：真人看完整卡片搶答，全婉拒輪詢電腦，介紹費照收。

**翻機會卡現金紅色** ✅　「要翻哪一堆機會」與二選一卡上的現金數字改為紅色加大加粗，一眼看到口袋深度。

**合資出資比受現金限制** ✅　滑桿上限＝你的現金出得起的比例（現金 100 拉不了 1000 的股份）；連最低出資比都出不起時明講並鎖住「提出」。
